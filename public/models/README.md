# 3D Models

Place your shoe rack glTF file in this directory.

## Instructions:
1. Export your Rhino file as GLB (recommended) or GLTF
2. Name it `shoerack.glb` (or `shoerack.gltf`)
3. Place it in this `/public/models/` folder
4. The ShoeRackViewer component will automatically load it

If you exported as GLTF (not GLB), make sure to also include all the accompanying .bin and texture files in this folder.
